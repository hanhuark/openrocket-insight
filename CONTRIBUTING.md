# Contributing

Thank you for improving OpenRocket Insight.

## First contributions

Open an issue describing the user task, source data format, expected behavior, units, and a small reproducible example. Do not upload private launch locations, student information, or proprietary rocket designs.

## Development expectations

- Keep source simulation output and derived normalized data traceable.
- Do not silently convert or infer units.
- Add or update a test for behavior changes.
- State whether an example is simulated, measured, or illustrative.
- Keep safety-related language conservative: this package is analysis support, not flight approval.
